# CU16 · Consultar seguimientos

| | |
|---|---|
| RF | RF05 |
| Actor | Paciente (el médico lo hereda, D-005) |
| Fase / iteración | Construcción · It9 (con CU10, D-016) |
| Módulo | servidor 1.8.0 (paquete `seguimiento`) |
| Rama | `feature/It09-seguimiento-servidor` |

## Flujo principal
1. El paciente consulta sus seguimientos: tipo de prueba, periodicidad, revisiones generadas / prescritas,
   estado y fecha de la próxima revisión.
2. El paciente consulta las revisiones de uno de sus seguimientos: las solicitudes generadas y su estado
   (SOLICITADA, CITADA, REALIZADA, INFORMADA, CANCELADA).

## Flujos alternativos
- Seguimiento de otro paciente → `AccesoDenegadoException` (RNF-S3); inexistente → `NoEncontradoException`.
- Usuario sin paciente asociado (p. ej. un médico que no es paciente) → `ReglaNegocioException`.

## Contratos
- `api.ApiMisSeguimientos` (permiso `CONSULTAR_MIS_SEGUIMIENTOS`, datos clínicos).

## Diseño de pruebas
| Entrada | CEV | CEI |
|---|---|---|

| Usuario | con paciente asociado | sin paciente asociado |
| Rol | Paciente, Médico | Administrativo |
