# CU03 · Configurar catálogo y parámetros

| | |
|---|---|
| RF | RF17 |
| Actor | Administrador (el resto de roles solo consulta) |
| Fase / iteración | Elaboración · It3 |
| Módulo | servidor 1.2.0 (paquete `catalogo`) |
| Rama | `feature/CU03-servidor` |

## Flujo principal
1. El administrador da de alta, modifica o da de baja tipos de prueba: código, nombre, modalidad, sala,
   duración, preparación, contraste, consentimiento, requisitos de seguridad y si admite seguimiento.
2. El administrador ajusta los parámetros: horario del servicio, plazo máximo de espera por prioridad y
   antelación de los recordatorios.

## Flujos alternativos
- 1a. Código repetido → `ReglaNegocioException`; duración fuera de [5, 240] o contraste sin consentimiento → `IllegalArgumentException`.
- 2a. Apertura ≥ cierre, plazo fuera de [1, 365] o que rompa URGENTE ≤ PREFERENTE ≤ ORDINARIO, recordatorio fuera de [1, 168] h → `IllegalArgumentException`.

## Contratos
- `api.ApiCatalogo` (permisos `CONSULTAR_CATALOGO`, `CONFIGURAR_SISTEMA`).
- `catalogo.ServicioCatalogo`, `catalogo.ParametrosSistema` (los usan agendas, citas, esperas y notificaciones).

## Diseño de pruebas
| Entrada | CEV | CEI | Valores límite / conjetura de errores |
|---|---|---|---|
| Duración (min) | [5, 240] | < 5; > 240 | 4, 5, 240, 241 |
| Contraste × consentimiento | (F,F), (F,V), (V,V) | (V,F) | tabla de decisión completa |
| Horario | apertura < cierre | apertura = cierre; apertura > cierre; nulos | intervalo [07:59–08:30], [20:30–21:01] |
| Plazo (días) | [1, 365] respetando el orden | 0; 366; romper el orden | URGENTE 0/1/15/16; ORDINARIO 14/15/365/366 |
| Recordatorio (h) | [1, 168] | 0; 169 | 0, 1, 168, 169 |
| Rol | Administrador | Paciente, Médico, Administrativo (solo consultan) | — |
