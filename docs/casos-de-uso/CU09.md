# CU09 · Gestionar informes e imágenes

| | |
|---|---|
| RF | RF09 |
| Actor | Médico; RIS/PACS |
| Fase / iteración | Construcción · It8 (con CU08, D-016) |
| Módulo | servidor 1.7.0 (paquete `informes`) |
| Rama | `feature/It08-clinico-servidor` |

## Flujo principal
1. El médico crea el informe (hallazgos y conclusión) de una prueba REALIZADA; la solicitud pasa a INFORMADA.
2. El paciente recibe el aviso INFORME_DISPONIBLE (CU12).
3. El médico consulta el informe de una solicitud, los informes de un paciente y las imágenes del PACS.

## Flujos alternativos
- Prueba no realizada o ya informada → `ReglaNegocioException`; solicitud sin informe → `NoEncontradoException`.
- RNF-S3: el médico solo accede a pacientes que atiende (les pidió alguna prueba o están en su agenda) → si no, `AccesoDenegadoException`.

## Diseño de pruebas
| Entrada | CEV | CEI | Conjetura de errores |

| Hallazgos / conclusión | texto | vacío | — |
| Médico | solicitante; médico de la agenda | médico que no atiende al paciente | — |
| Rol | Médico | Paciente, Administrativo, Administrador | — |
