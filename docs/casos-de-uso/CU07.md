# CU07 · Gestionar mis citas

| | |

| Rama | `feature/It07-paciente-servidor` |

## Flujo principal
1. El paciente consulta sus citas ordenadas por fecha.
2. Confirma su asistencia (PROGRAMADA → CONFIRMADA), o
3. solicita un cambio indicando el motivo (→ CAMBIO_SOLICITADO); admisión ve la lista y la reprograma (CU06), o
4. cancela la cita: se libera el hueco, la solicitud vuelve a la lista de espera y recibe el aviso (CU12).

## Flujos alternativos
- La cita es de otro paciente → `AccesoDenegadoException`.
- La cita ya ha empezado o pasado → `ReglaNegocioException`.
- Confirmar una cita que no está PROGRAMADA o pedir un cambio de una cita cancelada → `ReglaNegocioException`.
- Usuario sin paciente asociado → `ReglaNegocioException`.

## Contratos
- `api.ApiMisCitas` (permiso `GESTIONAR_MIS_CITAS`); `ApiCitas.conCambioSolicitado` para admisión.
